# Hypno 🔍

**Hypno** is a lightweight Firefox extension for web reconnaissance that extracts endpoints and parameters from web pages.
Built with a focus on simplicity, useful results, and manual web security testing.

<img width="420" height="498" alt="ss" src="https://github.com/user-attachments/assets/ad7140e7-ca88-4fc7-8ea9-b8ec4a65fffc" />

## ✨ Features
- 🔗 Extract endpoints from links and external scripts
- 🔎 Extract URL query parameters
- 📝 Extract HTML input name and id attributes
- ⚙️ Extract JavaScript variables
- 📦 Extract keys from JSON data
- ♻️ Automatically remove duplicate results
- 📋 Copy extracted results
- 📤 Export results as .txt
- 🦊 Built for Firefox

## 🚀 Installation
### Firefox Add-ons
Hypno is now officially available on the Firefox Add-ons store.

#### 👉 Install Hypno:
https://addons.mozilla.org/en-US/firefox/addon/hypno/

### Manual Installation
1. Clone the repository:
```bash
git clone https://github.com/MaMad4Ever/Hypno.git
```
2. Open Firefox and navigate to:
`about:debugging`
3. Select This Firefox.
4. Click Load Temporary Add-on...
5. Select the `manifest.json` file from the Hypno directory.
6. Open any web page and launch Hypno from the Firefox toolbar.

## 🛠️ Usage
1. Open a web page.
2. Click the Hypno extension.
3. Click Scan Page.
4. Switch between:
   - Endpoints
   - Parameters
5. Use Copy All or Export to save the results.


## ⚠️ Disclaimer

Hypno is intended for authorized security testing and educational purposes only.

Only use it on websites and applications where you have **permission to perform security testing**.
